## Esta é uma pequena apresentação do sistema de prescrição hospitalar que desenvolvi e disponibilizei para Santa Casa de Dracena enquanto atuei como Analista de TI.
## O projeto conta com Cadastro de usuários com permissões, Cadastro de Setores, Leitos, Pacientes (nesse caso tem integreção com outro sistema), Convênios, Exames, entre outras funcionalidades básicas.
